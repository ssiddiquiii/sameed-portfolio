# Sameed Siddiqui — Portfolio

Personal portfolio website built with **React** and **Vite** to showcase software projects, engineering stack, and educational content.

**Live Site:** [https://sameedsiddiqui.me](https://sameedsiddiqui.me)

---

## Tech Stack

- **Framework:** React 18
- **Bundler:** Vite 5
- **Styling:** Vanilla CSS + Tailwind CSS utilities
- **Design Tokens:** CSS Variables (Light & Dark mode)
- **Deployment:** Vercel

---

## Features

- Fully responsive layout across mobile, tablet, and desktop
- Native dark / light mode with `localStorage` persistence
- Touch-friendly hamburger navigation on mobile & tablet
- Fast load times with zero third-party UI framework bloat

---

## Local Development

```bash
# Clone the repository
git clone https://github.com/ssiddiquiii/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application runs locally at `http://localhost:5173`.

---

## Production Build

```bash
npm run build
npm run preview
```
